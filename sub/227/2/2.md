# 2. Application for licence.
Every person desiring to obtain a licence to install or work any apparatus for wireless telegraphy shall apply in writing to the Minister and shall give the following particulars–
(a) his full name, nationality and address;
(b) the address at which the apparatus is to be installed;
(c) the name of the apparatus, the description of the set, the maker’s name, and the number of valves in use.
