# 21. Communicating from Office.
All correspondence from the Office to an applicant shall be sent–
(a) to the agent of the applicant if an agent who is resident in Belize has been appointed;
(b) if no agent has been appointed in Belize to the address for service of the applicant in Belize;
(c) to the applicant, if no agent has been appointed in Belize to represent the applicant and the applicant has no address for service filed in the Office.
