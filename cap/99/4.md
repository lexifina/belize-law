# 4. Acts done partly within and partly beyond court’s jurisdiction.
Where an act which, if done wholly within the jurisdiction of a court, would be a summary conviction offence cognisable in that court, is done partly within and partly beyond that court’s jurisdiction, every person who, within the jurisdiction, does or abets any part of that act shall be liable to be proceeded against and convicted and punished for the offence in the same manner as if the act had been done wholly within the jurisdiction.
